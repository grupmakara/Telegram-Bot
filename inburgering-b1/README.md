# Inburgering B1 – Türkçe açıklamalı çalışma uygulaması

Tek dosyalık, kurulum gerektirmeyen mobil uyumlu çalışma uygulaması.

- `index.html` — telefonda veya bilgisayarda doğrudan tarayıcıda açılır (internet gerekmez, yalnızca yazı tipleri ve sesli okuma için tarayıcı özellikleri kullanılır).
- `app.html` — aynı uygulamanın claude.ai Artifact olarak yayınlanan sürümü.

İçerik: 21 gramer dersi (Türkçe kural + örnek + alıştırma), 120+ kelime kartı, Lezen, Luisteren (tarayıcının Hollandaca sesiyle), Spreken (120 soru + zamanlayıcı), Schrijven (30 görev + kelime sayacı), KNM (8 tema + test), fiil bankası, 12 haftalık plan ve karışık deneme sınavı. İlerleme tarayıcıda (localStorage) saklanır.
